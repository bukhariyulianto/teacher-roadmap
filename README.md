# 🕌 Modul Kompetensi Digital Calon Guru Islam

**Roadmap Checklist & Instrumen Implementasi Kurikulum (SPMI/OBE)**

Modul ini merupakan aplikasi pembelajaran digital interaktif yang dirancang untuk membantu perguruan tinggi Islam, dosen, dan mahasiswa dalam membangun **kompetensi digital calon guru Islam** secara bertahap, terukur, dan berorientasi pada capaian pembelajaran.

Aplikasi dikembangkan dalam format **web interaktif**, sehingga dapat digunakan melalui browser pada perangkat desktop maupun mobile.

---

## 🎯 Tujuan

Modul ini dirancang untuk mendukung terbentuknya lulusan yang:

* 🧑‍🏫 Profesional sebagai guru Islam.
* 💻 Memiliki literasi dan kompetensi digital.
* 🤖 Mampu memanfaatkan Artificial Intelligence (AI) dalam pendidikan.
* 🎨 Mampu menghasilkan media pembelajaran digital.
* 🖥️ Mampu mengelola pembelajaran menggunakan LMS.
* 🌐 Mampu membangun dan mengelola website pendidikan.
* 👥 Mampu melakukan kolaborasi digital.
* 📂 Memiliki portofolio digital.
* 🛡️ Memahami etika, keamanan, dan tanggung jawab dalam penggunaan teknologi.

Target akhir modul adalah **Guru Islam Profesional yang memiliki kompetensi digital, AI, media pembelajaran, dan etika teknologi**.

# 🚀 Cara Menjalankan

## 1. Download Repository

Clone repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Masuk ke folder:

```bash
cd REPOSITORY
```

## 2. Jalankan

Buka file:

```text
modul_edu_digital.html
```

langsung menggunakan browser.

Alternatifnya, gunakan local server:

```bash
python -m http.server 8000
```

Kemudian buka:

```text
http://localhost:8000
```
